# Dreamline Business Analytics Dashboard

This Power BI dashboard analyzes visa and ticket sales data to track revenue, application trends, and business KPIs.

## Tools Used
- Power BI
- Power Query
- DAX

## Key Insights
- Visa and ticket sales performance by type and region
- Customer trends and revenue growth
- Interactive visuals for business decision-making
